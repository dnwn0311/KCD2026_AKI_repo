# KCD 2026 · ICU AKI 위험 예측 코드 전달본

작성 2026-10-16 · 정리: 김우주

이 폴더에는 세 가지가 들어 있습니다.

0. **전처리**: MIMIC-IV 원본에서 위험 모델 입력(코호트, KDIGO 라벨, 시간별·입실별 특징, 분할)을 만드는 팀원 파이프라인과 실행 도구입니다. 약물 플래그 수정과 추세 특징 생성은 1번 폴더에 있습니다. 자세한 흐름은 `0_전처리/README.md`를 보세요.
1. **팀 위험 모델 (확정 모델)**: 입실 48시간 시점에서 이후 24시간 안의 첫 AKI를 예측하는 LightGBM에 추세 특징 26개를 더한 모델과, 그 변수 기여도·값 목록을 만드는 코드입니다.
2. **논문 재현 (Qian 2021)**: "Prediction Models for AKI in ICU: A Comparative Study"의 방식을 MIMIC-IV에 그대로 옮겨 본 코드입니다. 논문의 LightGBM 0.905가 재현되는지 확인하려고 만들었습니다.

환자 단위 자료와 학습된 모델 파일은 들어 있지 않습니다. `3_결과_집계/`에는 집계 결과만 있습니다.

## 1. 결과 한눈에 보기

### 팀 위험 모델 (테스트 1,658건, 양성 261건)

| 모델 | AUROC | AUPRC |
|---|---|---|
| 기준 특징만 (254개) | 0.754 | 0.355 |
| **기준 + 추세 특징 26개 (확정, 280개)** | **0.775** | **0.373** |

- 추세를 더한 효과: AUROC 차이의 부트스트랩 95% 구간 [0.006, 0.037]. 구간이 0을 넘지 않지만 폭이 넓어 "약 0.02 향상, 크기는 불확실"로 말하는 편이 안전합니다.
- 알고리즘 비교 (같은 특징·같은 분할, 시드 3개 평균 AUROC): LightGBM 0.771, XGBoost 0.768, RandomForest 0.757, 로지스틱 회귀 0.752. LightGBM과 XGBoost의 차이는 0.002 안팎으로 사실상 같습니다.
- 신호등 (검증셋 기준 상위 5% 빨강, 15% 노랑 이상): 테스트에서 빨강은 알림 6.0%, 민감도 19.5%, 양성예측도 51.5%. 노랑 이상은 알림 15.6%, 민감도 37.2%, 양성예측도 37.6%.
- 라벨 기준별: 크레아티닌 기준 양성 AUROC 0.763, 소변량만 기준 양성 0.785.
- 코호트: 입실 11,000건(환자 10,211명), 양성 1,733건(15.8%). 분할은 환자 단위 70/15/15 `split_random`.

### 논문 재현 (Qian 2021 방식, MIMIC-IV 3.1)

| 모델 | 논문 AUC | 재현 (논문 방식) | 재현 (엄격 조건) |
|---|---|---|---|
| LightGBM | 0.905 | 0.811 | 0.769 |
| RF | 0.728 | 0.799 | 0.763 |
| XGBoost | 0.760 | 0.796 | 0.748 |
| CNN | 0.718 | 0.789 | 0.744 |
| LR | 0.736 | 0.788 | 0.741 |
| SVM | 0.737 | 0.786 | 0.739 |

엄격 조건은 `--strict --exclude-day1-aki`입니다. 결측 보완을 학습 데이터에서만 학습하고, 입실 첫 24시간 안에 이미 AKI인 입실을 뺀 것입니다.

- 논문의 LightGBM 0.905는 재현되지 않았습니다. 순위(LightGBM 1위)는 같지만 다른 모델과의 차이는 0.01~0.02입니다.
- 레이블 섞기 AUC는 0.499라서 기계적인 누수는 없습니다. 크레아티닌을 빼도 LightGBM이 0.811에서 0.796으로 조금만 떨어집니다.
- 입실 첫 24시간 안에 이미 크레아티닌이 0.3 이상 오른 입실이 전체의 5.8%(3,382건)입니다. 이 중 79.2%가 양성이고, 전체 양성의 약 4분의 1을 차지합니다. 이들을 빼면 LightGBM이 0.769입니다.
- 두 실험은 과제가 달라서 AUC를 직접 비교하지 않습니다. 팀 모델은 입실 48시간 시점에서 24시간 뒤를, 논문 방식은 첫 24시간 자료로 72시간 안을 예측합니다. 논문 방식은 균형화(50:50)한 데이터에서 평가합니다.

## 3. 준비물

- **데이터는 들어 있지 않습니다.** MIMIC-IV 3.1 접근 권한(PhysioNet)이 필요합니다.
- 팀 위험 모델은 팀원 전처리(`mimic-iv-aki-preprocessing`)의 산출물을 입력으로 씁니다: `cohort_final.parquet`, `wide.parquet`, `splits.parquet`, `default_features.json`, `hourly.parquet`. 이 산출물을 만드는 코드가 `0_전처리/`입니다(`bash 0_전처리/wsl_team_pipeline.sh`, 설명은 `0_전처리/README.md`).
- 파이썬 환경은 `pip install -r requirements.txt`. LightGBM은 4.7.0으로 확정 모델을 학습했습니다. CNN이 필요 없으면 `torch`는 생략하고 `--skip-cnn`을 씁니다.
- **자료 취급 규칙**: 환자 단위 자료(`_work/`, `qian_table.parquet` 등)는 이 PC 밖으로 내보내지 않고, 외부 온라인 LLM·API에도 보내지 않습니다. 화면과 파일에는 집계만 남기며 10 미만 건수는 `<10`으로 가립니다. `.gitignore`가 `_work/`, `runs/`, `*.parquet`을 막아 두었습니다.

## 4. 팀 위험 모델 실행 (`1_팀위험모델/`)

모든 명령은 `1_팀위험모델/` 폴더 안에서 실행합니다. 가장 쉬운 방법은 한 번에 돌리는 것입니다.

```bash
cd 1_팀위험모델
PIPE=$HOME/aki_pipeline bash run_team_model.sh      # PIPE = 팀원 전처리 폴더
```

단계별로 하려면 다음과 같습니다.

| 단계 | 명령 | 하는 일 | 결과 |
|---|---|---|---|
| 0 | 팀원 전처리 파일 4개를 `_work/team/`에 복사 | 입력 준비 | `_work/team/*.parquet`, `default_features.json` |
| 1 | `python patch_drug_flags.py --proj $PIPE` | NSAID·ACEi/ARB 플래그 수정 | `_work/team_fixed/` |
| 2 | `python train_risk_trend.py --team-dir _work/team_fixed --hourly $PIPE/data/features/hourly.parquet --save` | 추세 특징 생성, 기준 vs +추세 학습, 확정 모델 저장 | `results/eval_team_risk_trend.json`, `runs/aki_risk_team_trend/`, `_work/team_fixed/risk_scores_trend.parquet` |
| 3 | `python compare_models.py` | 알고리즘 비교 | `results/eval_team_risk_models.json` |
| 4 | `python feature_contrib.py` | 변수 기여도 | `feature_contrib/feature_contrib_all.csv` 등 |
| 5 | `python feature_values.py` → `python feature_catalog.py` | 값 예시, 280개 값 목록 | `feature_contrib/feature_value_examples.csv`, `feature_catalog.csv` |

- 0단계 이전에 `0_전처리/`의 파이프라인을 먼저 돌려 팀원 산출물(`$PIPE/data/...`)을 만들어 둡니다.
- 1단계(`patch_drug_flags.py`)는 `duckdb`와 팀원 환경의 `prescriptions.parquet`이 필요합니다. 이미 수정본(`_work/team_fixed/`)이 있으면 건너뜁니다.
- 2단계의 `--save`를 빼면 모델과 점수 파일은 저장하지 않고 평가 JSON만 만듭니다.
- 4~5단계는 2단계의 `--save`로 만든 `runs/aki_risk_team_trend/`가 있어야 합니다.
- 분할은 `--split split_random`(기본), `split_temporal`, `split_hybrid` 중 고를 수 있습니다.

### 모델 구성 (재현에 필요한 설정)

- 입력: 팀원 `default_features.json`의 wide 열 중 라벨·시점·분할·퇴원 시 부여되는 정보(`esrd_chronic_dialysis` 등)를 코드에서 한 번 더 걸러낸 254개 + 추세 26개 = 280개. 범주형은 병동, 성별, 입원 유형 3개.
- 추세 26개: 크레아티닌 변화·기울기·최저 대비 상승(9개), BUN·칼륨·중탄산 변화와 BUN/크레아티닌 비(4개), 소변량 속도·저하 시간(7개), 평균동맥압 최저·65 미만 시간(2개), 수액·소변·수분 균형(3개), 승압제 시간(1개)을 입실 0~47시간 자료에서 계산합니다. 정의는 `train_risk_trend.py`의 `build_trend`와 `TREND_KR`에 있습니다.
- LightGBM: 학습률 0.03, 잎 15개, `min_child_samples` 30, `subsample` 0.8, `colsample_bytree` 0.5, `reg_lambda` 2.0, 시드 42, 검증 AUROC 기준 조기 종료(150라운드). 확정 모델은 223그루.
- 보정: 검증셋에서 isotonic 회귀를 맞춰 테스트 확률에 적용합니다. 신호등 기준은 검증 위험 상위 5% 빨강, 15% 노랑 이상입니다.

## 5. 논문 재현 실행 (`2_논문재현_Qian2021/`)

```bash
cd 2_논문재현_Qian2021
MIMIC_ROOT=$HOME/aki_pipeline/data/mimiciv/3.1_parquet bash run_qian.sh
```

직접 실행하면 다음과 같습니다.

```bash
# 1) 표 만들기 (환자 단위 파일이 생기므로 PC 밖으로 내보내지 않음)
python qian2021_replicate.py build --mimic-root <MIMIC-IV 폴더> --out qian_table.parquet
# 2) 논문 방식
python qian2021_replicate.py run --table qian_table.parquet --out qian_out
# 3) 엄격 조건
python qian2021_replicate.py run --table qian_table.parquet --out qian_out_strict --strict --exclude-day1-aki
```

- `<MIMIC-IV 폴더>`는 `hosp/*.parquet`, `icu/*.parquet`(또는 `.csv.gz`) 구조여야 합니다. 파일이 흩어져 있으면 `--patients-file`, `--chartevents-file`로 직접 지정합니다. 우리 PC의 예: `--mimic-root /mnt/d/MIMIC/mimiciv --patients-file /mnt/d/MIMIC/patients.csv.gz --chartevents-file /mnt/d/MIMIC/chartevents.csv-001-013.gz`
- 소요 시간은 `build`가 수 분(chartevents 한 번 스캔), `run`이 모델 6개 × 10회 반복입니다. torch가 없으면 `--skip-cnn`.
- 논문에 없는 부분(하이퍼파라미터, CNN 구조, 소변량 기준의 구체 구현, BMI 계산)은 라이브러리 기본값과 가정으로 채웠고, 코드의 `ASSUMPTION` 주석으로 표시했습니다.
- `run`은 점검 결과도 함께 냅니다(`summary.txt`의 `[점검]` 블록): 1일차 AKI 포함 여부별 AUC, 레이블 섞기, 크레아티닌 제거.

## 6. 결과를 읽을 때 주의할 점

1. **두 실험의 AUC를 직접 비교하지 않습니다.** 과제(예측 시점, 구간, 코호트)가 다릅니다. "논문이 0.9인데 우리는 0.775"가 아니라 "같은 설계로 재현하면 0.81이고, 이미 진행된 AKI를 빼면 0.77"로 설명합니다.
2. **균형화한 평가의 정확도·F1은 실제 값이 아닙니다.** 논문 방식의 정확도·정밀도·재현율·F1은 50:50 테스트셋 기준입니다. 실제 유병률(약 16~19%)에서의 양성예측도는 훨씬 낮습니다. 보고는 AUC만 사용하세요.
3. **약 변수는 위험 점수에 거의 반영되지 않습니다.** 신독성 10군 중 모델이 쓴 것은 루프이뇨제, 피페라실린-타조박탐, 약물군 개수 변수뿐이고, 280개 중 91개(ATC3 74개 포함)는 한 번도 쓰이지 않았습니다. 이 점수는 처방을 바꿨을 때의 위험 변화를 추정하지 못합니다. 약물 안전성 확인은 RAG 검증이 맡습니다.
4. **변수 기여도 해석**
   - `urine_ml_n_hours_obs`(2위), `tr_uo_obs_12h`, `hr_n_hours_obs` 같은 "기록된 시간 수" 변수는 생리 신호라기보다 도뇨관 유무와 모니터링 강도를 반영할 수 있습니다.
   - `first_careunit`(1위)는 Neuro Intermediate·Neuro Stepdown(코호트의 약 20%, AKI 약 4%)이 크게 좌우합니다.
   - 값 구간별 AKI 비율은 다른 변수를 보정하지 않은 단순 비교입니다.
5. **재현 실험의 한계**: 엄격 실행은 `--strict`와 `--exclude-day1-aki`를 동시에 켠 것이라 두 효과를 따로 뗀 값이 아닙니다(기본 실행의 "1일차 AKI 없음" 하위군 0.775와 비교하면 보완 방식의 영향은 약 0.006으로 작습니다). 균형화를 먼저 하고 나누므로, 같은 환자의 다른 입실이 학습과 테스트에 함께 들어갔는지는 `--first-stay-per-patient` 사용 여부에 따라 달라지며 아직 확인하지 못했습니다.

## 8. 재현성 메모
