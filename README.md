# KCD 2026 데이터톤: ICU 급성 신손상(AKI) 위험 예측 → 처방 변경 초안 → RAG 검증

MIMIC-IV 3.1 ICU 환자에서 **48시간 시점 이후 24시간 안에 AKI가 생길 위험**을 예측하고, 그 위험을 바탕으로 **LLM이 처방 변경 초안**을 만들고, **RAG로 근거를 검증**한 뒤 **임상의가 최종 결정**하는 흐름을 만든 프로젝트입니다. 이 저장소는 그중 AI 파트(작성: 김우주)의 코드와 집계 결과를 담습니다.

> **데이터는 이 저장소에 없습니다.** MIMIC-IV는 PhysioNet 자격 서명이 필요한 자료이므로 환자 단위 파일(parquet, jsonl, 모델 가중치, 환자 점이 찍힌 그림)은 올리지 않았습니다. 올라온 숫자는 모두 집계값이며, 10건 미만 칸은 가렸습니다. 재현하려면 본인의 PhysioNet 권한으로 MIMIC-IV를 받아 전처리부터 실행해야 합니다.

## 실행 순서(개요)

1. 환경: `pip install -r requirements.txt` (GPU가 필요한 단계는 4번 폴더의 LLM 학습·생성뿐입니다)
2. 전처리: MIMIC-IV 경로를 설정하고 `0_전처리/`의 스크립트로 입실 코호트와 특징표를 만듭니다.
3. 위험 모델: `1_팀위험모델/run_team_model.sh` (학습 → 성능 곡선 → 보정 → 슬라이드용 지표표)
4. 선택 실험: `1_팀위험모델/결과론적피처제외/`, `2_논문재현_Qian2021/`
5. 처방 초안: `4_처방초안_LLM_RAG/`의 `prep_rx.py` → `train_qlora.py` → `make_drafts.py`, 검증은 `rag_progress.py`, `eval_safety.py`

스크립트는 작업 폴더에서 실행하는 것을 전제로 짜여 있어, 폴더 구조가 정리되기 전 경로를 쓰는 곳이 남아 있을 수 있습니다. 실행 중 `data/`, `_work/`, `runs/`가 로컬에 생기며 `.gitignore`로 제외됩니다. 전달용 안내는 `4_처방초안_LLM_RAG/docs/`에 있습니다.

## 알려진 한계

- 단일 기관(MIMIC-IV, 미국 한 병원) 데이터이며 외부 검증은 하지 않았습니다.
- 라벨이 크레아티닌·소변량 기반이라, 소변량 흐름 변수가 기여도 1위(그룹 합 약 27%)입니다. 결과를 일부 반영하는 변수가 아닌지 `결과론적피처제외` 실험으로 점검했고(모두 끄면 시험 AUROC 0.741, 모두 켜면 0.753), 해석에 주의가 필요합니다.
- SHAP 기여도는 모델이 쓰는 방식을 보여 줄 뿐 인과가 아닙니다.
- LLM 처방 초안은 임상의가 검토하기 전의 **제안**이며, 자동으로 처방을 바꾸지 않습니다. 약물 목록(약 34개)은 신장 관련 약에 한정됩니다.
- 신호등(주의·위험) 기준에서는 위험 구간의 민감도가 낮습니다(0.18). 놓치는 환자가 많다는 뜻이므로 임상 도구로 쓰기 전 반드시 별도 검증이 필요합니다.

## 데이터 이용

MIMIC-IV 데이터와 그로부터 만든 환자 단위 자료는 PhysioNet Credentialed Health Data License를 따르며, 이 저장소에 포함되어 있지 않습니다. 외부 온라인 LLM 서비스에 환자 정보를 넣지 마세요.
